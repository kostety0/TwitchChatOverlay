# Данные для регистрации приложения в консоли разработчика Twitch

Заполняется на <https://dev.twitch.tv/console/apps> → **Register Your Application** (или **Manage** у существующего приложения).

> **Важно:** это регистрация *Application*, а не *Extension*. TwitchChatOverlay — десктопная программа, она не может быть Расширением Twitch: расширения выполняются в браузере зрителя и не способны добавить звук в трансляцию. Подробнее — в разделе «Почему не Extension» ниже.

---

## Поля формы

| Поле | Значение |
|---|---|
| **Name** | `TwitchChatOverlay` |
| **OAuth Redirect URLs** | `http://localhost` |
| **Category** | `Broadcaster Suite` (альтернатива — `Chat Bot`) |
| **Client Type** | `Public` |

**`Client Type: Public` обязателен.** Приложение авторизуется через OAuth Device Code Flow — поток для публичных клиентов, без client secret. Если выбрать `Confidential`, вход по коду перестанет работать.

**Про `Category`:** приложение не пишет в чат и не отвечает на команды, а служит инструментом стримера, поэтому `Broadcaster Suite` описывает его точнее, чем `Chat Bot`. Функционально выбор ни на что не влияет.

---

## Запрашиваемые права (scopes)

Указывать при регистрации не нужно — они передаются в момент авторизации. Приводятся для полноты:

| Scope | Зачем |
|---|---|
| `user:read:chat` | чтение сообщений чата через EventSub |
| `channel:read:redemptions` | активации награды за баллы канала (только для режима «Только за баллы канала») |

Права на отправку сообщений, изменение канала, доступ к почте, платежам и списку подписчиков **не запрашиваются**.

### Короткое описание (до 200 символов)

```
Оверлей чата Twitch для Windows: показывает сообщения поверх игры и озвучивает их синтезом речи. Локальный синтез, без облачных сервисов.
```

### Полное описание

```
TwitchChatOverlay — десктопное приложение для Windows, которое показывает сообщения
из чата Twitch в закреплённом углу экрана поверх игры и озвучивает их синтезом речи.

Оверлей не забирает фокус у полноэкранного приложения и не сворачивает игру: окно
создаётся с расширенным стилем WS_EX_NOACTIVATE, а клики проходят сквозь карточку
в игру. В процесс игры ничего не внедряется — DirectX, Vulkan и OpenGL не хукаются,
поэтому анти-читы на приложение не реагируют.

Синтез речи выполняется локально: движок Piper запускается как отдельный процесс,
резервный вариант — встроенный в Windows SAPI. Текст сообщений не отправляется
никаким внешним сервисам.

Возможности: настройка положения и внешнего вида карточки, выбор голоса с фильтром
по полу, скорость и высота тона, отдельное устройство вывода звука, уникальный
голос каждому зрителю, фильтры по правам зрителей и содержанию сообщений,
чёрные списки, кулдаун, ограниченная очередь, глобальные горячие клавиши,
тёмная тема, русский и английский интерфейс.
```

## Почему это не Extension

Расширение Twitch (Extension) — это веб-приложение на HTML и JavaScript, которое Twitch раздаёт со своего CDN и выполняет в браузере зрителя внутри плеера или панели канала. Отсюда следуют ограничения, несовместимые с задачей этого приложения:

1. **Звук.** Расширение может проиграть речь только в браузере конкретного зрителя, у каждого своя. Добавить звук в саму трансляцию оно не может — а озвучка чата нужна именно в потоке, чтобы её слышали все, включая тех, кто смотрит запись.

2. **Оверлей.** Смысл карточки в том, что она попадает в захват OBS и становится частью видео. Расширение рисуется поверх плеера у зрителя и в записи трансляции не сохраняется.

3. **Технология.** Расширение не может быть программой на .NET/WPF, а локальный синтез через Piper требует запуска процесса на машине — в песочнице браузера это невозможно.

Правильная модель распространения для такой программы — обычное десктопное приложение с зарегистрированным Twitch Application для доступа к API. Каталога сторонних десктопных программ у Twitch нет, поэтому распространение идёт через GitHub Releases.

Если когда-нибудь понадобится именно расширение, это будет отдельный продукт с другой задачей — например, панель канала, показывающая зрителям историю озвученных сообщений. Данные для неё приложение должно было бы куда-то выгружать, а это уже требует сервера и меняет политику конфиденциальности: сейчас всё остаётся на компьютере стримера.
