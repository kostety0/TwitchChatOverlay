# Сюда кладутся модели голосов Piper

Модели **не входят в состав приложения**: каждая весит около 60 МБ и распространяется под собственной лицензией.

## Что скачать

Русские голоса из проекта `rhasspy/piper-voices`:
<https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU>

Для каждого голоса нужны **два файла**: сама модель `.onnx` и её конфигурация `.onnx.json`. Без `.json` Piper не запустится.

## Куда положить

Прямо в эту папку. Вложенные каталоги тоже просматриваются, так что можно раскладывать по подпапкам.

```
Resources/voices/
├─ ru_RU-irina-medium.onnx
├─ ru_RU-irina-medium.onnx.json
├─ ru_RU-denis-medium.onnx
└─ ru_RU-denis-medium.onnx.json
```

## Доступные русские голоса и их пол

Приложение определяет пол голоса по имени файла — это нужно, чтобы переключатель «Мужской / Женский» на вкладке «Голос» фильтровал список одинаково для Piper и SAPI.

| Голос | Пол |
|---|---|
| `irina` | женский |
| `denis` | мужской |
| `dmitri` | мужской |
| `ruslan` | мужской |

Голоса с другими именами по умолчанию считаются мужскими. Чтобы добавить распознавание нового голоса, допишите его в словарь `PiperSpeakerGenders` в файле `Core/Speech/VoiceCatalog.cs`.

**Учтите:** если положить только мужские голоса, а в настройках выбран женский пол, список голосов будет пустым. Это не ошибка — переключите пол или добавьте `irina`.

## Качество

В названии файла закодировано качество: `x_low`, `low`, `medium`, `high`. Оно показывается в списке выбора голоса. `medium` — разумный компромисс между качеством и скоростью синтеза.

## Лицензии

Модели принадлежат их авторам и обучены на сторонних речевых корпусах. Комплектные файлы `.onnx.json` **не содержат указания лицензии**, поэтому перед распространением моделей вместе со сборкой проверьте условия в первоисточнике — в репозитории `rhasspy/piper-voices` и в лицензии соответствующего речевого корпуса.
