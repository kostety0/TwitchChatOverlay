# Сюда кладётся Piper

Движок синтеза речи Piper **не входит в состав приложения** — он распространяется под собственными лицензиями и скачивается отдельно.

## Что скачать

Windows-сборку Piper (`piper_windows_amd64.zip`) со страницы релизов проекта:
<https://github.com/rhasspy/piper/releases>

## Куда распаковать

Содержимое архива — прямо в эту папку, без вложенного каталога. Должно получиться так:

```
Resources/piper/
├─ piper.exe
├─ espeak-ng.dll
├─ onnxruntime.dll
├─ onnxruntime_providers_shared.dll
├─ piper_phonemize.dll
├─ libtashkeel_model.ort
└─ espeak-ng-data/        (папка с данными фонемизатора)
```

Модели голосов (`.onnx`) сюда класть **не нужно** — их место в `Resources/voices`.

## Если Piper не установлен

Приложение работает и без него: на вкладке «Голос» появится предупреждение с точным путём, куда положить `piper.exe`, и синтез автоматически переключится на встроенный в Windows движок SAPI. Русские голоса SAPI (Microsoft Irina, Microsoft Pavel) присутствуют в Windows при установленном русском языковом пакете.
