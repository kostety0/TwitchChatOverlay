### ⚠ Требования GPL-3.0 для espeak-ng

espeak-ng распространяется на условиях GNU General Public License версии 3. При распространении сборки, содержащей `espeak-ng.dll` и `espeak-ng-data`, необходимо выполнить следующее.

**1. Приложить текст лицензии.** Файл [`licenses/GPL-3.0.txt`](licenses/GPL-3.0.txt) включён в репозиторий и должен попасть в состав распространяемого архива.

**2. Обеспечить доступ к исходному коду espeak-ng версии 1.52.0.** Согласно GPL-3.0 §6(d), при распространении бинарников через сеть достаточно предоставить исходный код «тем же способом и в том же месте». Практически это означает: **приложить архив исходников espeak-ng 1.52.0 к тому же GitHub Release**, в котором лежат бинарники.

Источник: <https://github.com/espeak-ng/espeak-ng/releases/tag/1.52.0>

Недостаточно просто дать ссылку на сторонний сайт — источник может исчезнуть, а обязательство сохраняется. Копия архива в вашем релизе снимает этот риск.

**3. Указать факт использования и изменений.** Если вы не изменяли espeak-ng (а вы не изменяли — файл взят из готовой сборки Piper), достаточно указать это. Настоящий файл выполняет эту задачу.

### Почему GPL-3.0 не распространяется на код TwitchChatOverlay

Приложение **не связывается** с espeak-ng ни статически, ни динамически. Оно запускает `piper.exe` как отдельный процесс операционной системы, передаёт текст через стандартный ввод и читает результат из файла. Взаимодействие ограничено обменом данными через границу процессов, что не создаёт производного произведения от espeak-ng.

Следствие: исходный код TwitchChatOverlay остаётся под лицензией правообладателя (см. [`LICENSE`](LICENSE)), а обязательства GPL-3.0 касаются только компонента espeak-ng и выполняются способами, описанными выше.

Если вы распространяете сборку **без** папки `Resources/piper` — обязательства GPL-3.0 не возникают вообще. Приложение в этом случае использует встроенный в Windows синтез SAPI.

## 3. Модели голосов Piper

Файлы `.onnx` и `.onnx.json` в `Resources/voices/`.

| Модель | Источник |
|---|---|
| `ru_RU-irina-medium` | rhasspy/piper-voices |
| `ru_RU-denis-medium` | rhasspy/piper-voices |
| `ru_RU-dmitri-medium` | rhasspy/piper-voices |
| `ru_RU-ruslan-medium` | rhasspy/piper-voices |

**Лицензии моделей не объявлены в комплектных файлах.** Это проверено: поле `license` в файлах `.onnx.json` отсутствует у всех четырёх моделей.

Перед распространением моделей вместе со сборкой необходимо:

1. Установить лицензию каждой модели в первоисточнике — <https://huggingface.co/rhasspy/piper-voices> (файл `MODEL_CARD` рядом с моделью).
2. Проверить лицензию речевого корпуса, на котором модель обучена. Для русских голосов это, как правило, корпуса RUSLAN и подобные, у которых могут быть ограничения на коммерческое использование.
3. Внести установленные лицензии в настоящий файл и приложить их тексты.

**До выполнения этих шагов распространение моделей в составе релиза несёт юридический риск.** Наименее рискованный вариант — не вкладывать модели в релиз, а дать пользователю инструкцию по их скачиванию (она уже есть в `TwitchChatOverlay/Resources/voices/README.md`).

## 4. Прочее

Шрифт **Inter** упоминается в теме оформления как предпочтительный, но **не поставляется** с приложением. При его отсутствии используются системные шрифты Windows (Segoe UI Variable, Segoe UI). Права на Inter (SIL Open Font License 1.1) не затрагиваются.
