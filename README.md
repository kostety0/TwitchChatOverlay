# TwitchChatOverlay

Оверлей чата Twitch для Windows: показывает сообщения в закреплённом углу экрана поверх игры и озвучивает их синтезом речи. Всё настраивается через интерфейс — конфиги руками править не нужно.

**Версия:** 1.0.3 · **Автор:** Kostety0

---

## Ключевое

**Не сворачивает полноэкранную игру.** Окно оверлея создаётся с расширенными стилями `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`. `WS_EX_NOACTIVATE` здесь главный: без него всплывающая карточка забирает фокус и роняет игру в borderless-режиме. Клики проходят сквозь карточку в игру.

**Локальный синтез.** Текст сообщений не покидает компьютер: Piper запускается как локальный процесс, резервный вариант — встроенный в Windows SAPI. Облачных сервисов синтеза нет.

**Без инъекций в игру.** Ничего не хукается — ни DirectX, ни Vulkan, ни OpenGL. Анти-читы не реагируют.

## Возможности

- Карточка сообщения: цвет ника из Twitch, значки роли, настраиваемые шрифты, фон, прозрачность, скругление, 5 типов анимации
- Позиция хранится как «монитор + угол из 9 + отступ», поэтому не сбивается при смене разрешения. Режим настройки позволяет перетащить карточку мышью
- Голос: выбор движка и голоса, фильтр по полу, скорость, высота тона, громкость, выбор устройства вывода, шаблон произношения, транслитерация латинских ников в кириллицу
- Уникальный голос каждому зрителю — детерминированно по хешу его ID, один человек всегда звучит одинаково
- Фильтры: уровень доступа (все / подписчики / VIP / модераторы / только за баллы канала), чёрные списки слов и пользователей, обрезка длины, вырезание ссылок и эмоутов, игнор команд, схлопывание повторов, кулдаун на пользователя
- Очередь с ограничением размера и политикой вытеснения — под наплывом сообщений не растёт
- Глобальные горячие клавиши: заглушить, пропустить, очистить очередь, скрыть оверлей, открыть настройки
- Тёмная тема, русский и английский интерфейс с переключением на ходу

## Требования

- Windows 10 или 11, x64
- **.NET 8 Desktop Runtime** — только для обычной сборки:
  ```
  winget install Microsoft.DotNet.DesktopRuntime.8
  ```
  Автономная сборка (`--self-contained`) рантайм не требует.
- **Visual C++ Redistributable 2015–2022 x64** — только если используете Piper:
  ```
  winget install Microsoft.VCRedist.2015+.x64
  ```
- Своё приложение, зарегистрированное в [консоли разработчика Twitch](https://dev.twitch.tv/console/apps)

## Сборка

```bash
git clone <адрес репозитория>
cd TwitchChatOverlay
dotnet build
```

Обычная публикация:

```bash
dotnet publish TwitchChatOverlay/TwitchChatOverlay.csproj -c Release -o publish
```

Автономная, без зависимости от установленного .NET:

```bash
dotnet publish TwitchChatOverlay/TwitchChatOverlay.csproj -c Release -r win-x64 --self-contained true -o publish-standalone
```

Перед сборкой закройте приложение через трей — иначе сборка упрётся в заблокированный `.exe`.

## Первый запуск

1. Запустите `TwitchChatOverlay.exe` — окно настроек откроется само
2. Вкладка **Подключение**: зарегистрируйте приложение в консоли Twitch (кнопка ведёт туда) с параметрами:
   - **OAuth Redirect URL:** `http://localhost`
   - **Client Type:** `Public` — обязательно, иначе вход по коду не сработает
3. Вставьте **Client ID**, укажите имя канала
4. **«Войти через Twitch»** → введите показанный код на открывшейся странице
5. Индикатор «Состояние» станет зелёным

Авторизация нужна один раз: токен хранится зашифрованным через DPAPI и обновляется автоматически.

## Установка Piper (необязательно)

Без Piper приложение работает на SAPI. Чтобы получить более естественный голос:

## Где хранятся данные

| Что | Где |
|---|---|
| Настройки | `%APPDATA%\TwitchChatOverlay\settings.json` |
| Журналы (7 дней, с ротацией) | `%APPDATA%\TwitchChatOverlay\logs\` |

Текст сообщений чата в журналы не записывается. Подробнее — в [политике конфиденциальности](legal/PRIVACY.md).

## Архитектура

```
EventSub → MessageFilter → MessageQueue (bounded) → MessageDispatcher
                                                    ├─ синтез следующего заранее
                                                    ├─ показ карточки
                                                    └─ воспроизведение WAV
```

Диспетчер обрабатывает очередь строго последовательно, но синтезирует следующее сообщение параллельно с воспроизведением текущего — это убирает паузу между сообщениями без наложения голосов. Время показа карточки привязано к фактической длительности WAV плюс настраиваемый хвост, а не к фиксированному таймеру.

Стек: .NET 8, WPF, CommunityToolkit.Mvvm, TwitchLib.EventSub.Websockets, NAudio, Serilog, Microsoft.Extensions.Hosting.
